EZRA PICKS WEBSITE

This is a static website starter for GitHub Pages or Netlify.

BEFORE PUBLISHING
1. Open contact.html and replace your-email@example.com with an email address you check.
2. Review every page and edit the wording so it accurately reflects you and your site.
3. Add more original articles and actual useful content. The included guides are starter content, not hands-on product reviews.
4. Do not add affiliate links or claim Amazon Associates membership until you are eligible and the links/disclosure are accurate.
5. Amazon approval is not guaranteed. Review the current Amazon Associates policies for your marketplace.

PUBLISH WITH GITHUB PAGES
1. Sign in to GitHub and create a new public repository, e.g. ezra-picks.
2. Upload all files in this folder to the repository root. index.html must be in the root.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
5. Wait for GitHub Pages to publish. Your site will have a URL similar to:
   https://YOUR-USERNAME.github.io/ezra-picks/
6. Open that URL in a private/incognito window to confirm it works.
7. In Amazon Associates, enter the real, publicly accessible website URL, not the GitHub repository URL.

You can also deploy the folder through Netlify's manual deploy option.
